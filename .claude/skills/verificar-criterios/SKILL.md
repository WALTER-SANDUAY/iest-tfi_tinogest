---
name: verificar-criterios
description: Verifica cada requisito (RF) de una spec contra el código y los tests, y informa cuáles se cumplen. Usar al validar una funcionalidad.
---
Para cada RF de la spec:
1. Buscá en el código y en los tests dónde se implementa.
2. Marcá CUMPLE, NO CUMPLE o PRUEBA MANUAL PENDIENTE.
3. Si no cumple, indicá si la falla es del código o de la spec.
4. Citá el archivo y la línea que justifican cada marca.

No inventes evidencia: si no encontrás algo, decilo. No modifiques código.
