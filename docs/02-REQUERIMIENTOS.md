# 02 — Requerimientos

## Funcionales
| Código | Descripción | Prioridad |
|---|---|---|
| RF01 | El usuario puede registrarse e iniciar sesión con correo y contraseña | Alta |
| RF02 | Puede ver un calendario mensual y semanal de la agenda | Alta |
| RF03 | Puede crear, editar y eliminar turnos con fecha, hora y datos del cliente | Alta |
| RF04 | Puede buscar clientes por nombre o teléfono | Media |
| RF05 | Puede registrar ingresos con fecha, monto y descripción | Media |
| RF06 | Puede consultar un resumen de actividad del día o mes | Media |
| RF07 | Puede cerrar sesión de forma segura | Alta |

## No funcionales
- **RNF01**: Cualquier página debe cargar en menos de 3 segundos con conexión habitual.
- **RNF02**: La interfaz debe verse bien en teléfono, tablet y computadora.
- **RNF03**: Las contraseñas deben guardarse protegidas, nunca en texto plano.
- **RNF04**: Los menús y acciones deben entenderse sin necesidad de manual.
- **RNF05**: El sistema debe funcionar en navegadores comunes: Chrome, Firefox, Safari y Edge.
