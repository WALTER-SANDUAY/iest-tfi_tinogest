# 03 — Tecnologías elegidas

| Área | Herramienta | Motivo de elección |
|---|---|---|
| Frontend | Next.js (React) | Estructura ordenada, se adapta bien a equipos que van creciendo, buena documentación y facilita el acceso desde cualquier dispositivo |
| Base de datos | PostgreSQL | Es gratuita, potente, muy usada y se conecta bien con todas las herramientas elegidas |
| Autenticación | Supabase Auth | Simple de implementar, se integra con PostgreSQL y ya maneja la seguridad de las contraseñas |
| Repositorio | GitHub | Permite guardar el trabajo, volver a versiones anteriores y compartir avances fácilmente |
| Publicación | Vercel | Publicación automática, gratuita para proyectos de aprendizaje y se conecta directo con GitHub |
| IA de apoyo | Ollama (local) | Se puede usar sin conexión a internet y sin enviar datos externos, ideal para respetar la privacidad |
