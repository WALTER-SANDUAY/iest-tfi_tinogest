# 06 — Diseño de Interfaz

## Pantallas principales
| Pantalla | Contenido |
|---|---|
| Inicio | Bienvenida, resumen rápido del día, accesos directos |
| Agenda | Calendario, lista de turnos, botón "Nuevo turno" |
| Clientes | Buscador, listado, formulario de alta |
| Registros | Lista de ingresos, filtro por fechas |
| Sesión | Inicio, cierre y recuperación de contraseña |

## Aplicación de identidad visual
- **Botones**: fondo azul `#2563EB`, texto blanco; al pasar el cursor, se oscurece levemente. Botones de éxito en verde `#10B981`.
- **Tarjetas**: fondo blanco, bordes suaves, sombra ligera. Títulos en color oscuro `#1E293B`.
- **Formularios**: bordes grises claros; al estar activos, borde azul principal. Etiquetas con tipografía Inter.
- **Tipografía**: Montserrat para títulos; Inter para todo el resto.
- **Espaciado**: márgenes y espacios uniformes para que todo se vea ordenado.
