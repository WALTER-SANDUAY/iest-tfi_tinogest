# Spec 001 — Catálogo de vinos

## Cambio incorporado
- RF-09: El formulario mostrará la cepa en una lista desplegable con la opción "Otra..." que permite escribir un valor libre.
- RF-10: El formulario mostrará el año en una lista desplegable que incluya la opción "Sin año".
- RF-11: Al editar un vino, las listas mostrarán seleccionado el valor guardado.
